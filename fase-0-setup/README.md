# Fase 0 — Setup

## Objetivo
Dejar el entorno listo y reproducible en cualquier máquina, y este repo funcionando
(clonar/push desde cualquier sitio).

## Tareas
- [ ] Instalar el entorno (ver `../entorno.md`).
- [ ] Comprobar `torch`, `torchaudio`, `librosa`.
- [ ] Configurar git y las credenciales en las máquinas que uses.
- [ ] (Opcional) Abrir este repo como vault en Obsidian.

## Notas
Sin fecha límite; es puro andamiaje. En cuanto la comprobación rápida de `entorno.md`
pase, saltar a Fase 1.
